Theorem 3 If ω satisﬁes ω(t) = O(t) as t →∞then the following are equivalent:
(1) ω satisﬁes ∃C > 0 ∃t0 > 0 ∀λ ≥1 ∀t ≥t0 : ω(λt) ≤Cλω(t).
(2) There exists a sub-additive weight function ˜ω so that E[ω] = E[ ˜ω].
(3) E{ω} is stable under composition.
(4) E{ω} is stable under solving ODEs.
(5) E{ω} is stable under inversion.
(6) E{ω} is inverse-closed.
Theorem 4 If ω satisﬁes ω(t) = o(t) as t →∞then the following are equivalent:
(1) ω satisﬁes ∃C > 0 ∃t0 > 0 ∀λ ≥1 ∀t ≥t0 : ω(λt) ≤Cλω(t).
(2) There exists a sub-additive weight function ˜ω so that E[ω] = E[ ˜ω].
(3) E(ω) is stable under composition.
(4) E(ω) is stable under solving ODEs.
(5) E(ω) is stable under inversion.
(6) E(ω) is inverse-closed.
